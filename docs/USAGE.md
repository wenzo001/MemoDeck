# MemoDeck · 使用说明

面向使用者。开发者请看 [架构设计](./ARCHITECTURE.md)，题库格式看 [JSON 规范](./EXAM_JSON_SPEC.md)，
界面规格（颜色 / 字号 / 组件 / 断点 / 命名）看 [设计系统](./DESIGN_SYSTEM.md)。

## 一、最快上手

**双击 `index.html`**。就这样，不需要装任何东西，不需要联网。

页面会加载内置的示例题库（初中历史 13 题），打开落在**今日**页，你可以直接体验所有功能。

界面上只有四个一级入口：**今日 / 练习 / 错题本 / 题库**。手机宽度它们在底部标签栏，
宽度到 560px 以上自动变成左侧栏；窄到 320–359px 时底部只留「今日 / 练习 / 更多」三栏，
错题本与题库收在「更多」里。

## 二、导入自己的题库

所有跟数据有关的操作都在**题库**页（2.x 那个右上角的「数据管理」浮层已经并进这一页），
从上到下按分组排：当前题库 → 导入 → 手动加题 → 导出与备份 → 外观 → 关于。

「导入」分组里五种方式任选：

| 方式 | 操作 | 适用场景 |
|---|---|---|
| **拖拽文件** | 把 `.json` 文件拖进虚线框 | 本机已有题库文件 |
| **点击选择文件** | 点虚线框里的「点击选择文件」 | 同上，更明确的入口 |
| **粘贴 JSON** | 展开「或粘贴 JSON 文本录入」，粘贴后点「应用粘贴的 JSON」 | 从 AI 对话、聊天窗口里复制来的 JSON |
| **远程链接** | 填 URL 后点「远程导入」 | 题库托管在网上，希望随时刷新 |
| **放 `data.json`** | 把题库命名为 `data.json` 放在应用同目录 | 部署后希望打开即用（需 http/https） |

三种格式自动识别：exam-bank 标准、`papers` 数组、旧版分题型对象。导入成功后会写入浏览器
localStorage，**下次打开自动恢复**，不用重复导入；顶栏的来源标识会跟着变成「本地文件 · 时间」。

### 这一页上的其它按钮

- **刷新** —— 按当前数据源重新拉取
- **清空缓存并重载** —— 清掉缓存回到内置题库
- **下载题库 JSON / 复制 JSON / JSON 规则** —— 导出当前题库，或把格式说明丢给 AI
- **导出备份 / 导入备份** —— 备份含题库、学习进度、错题本与会话恢复点，**换设备用这个**；
  只下载题库 JSON 是不含进度与错题的
- **清空全部数据** —— 不可逆，确认走应用内对话框，正文点名要删掉什么
- **主题** —— 跟随系统 / 浅色 / 深色（深色是暖黑，主按钮反转成纸底墨字，不是把浅色机械调暗）
- **每日目标** —— 10 / 20 / 30 / 50 题或自定义，默认 20。它是「今日任务」的出题上限：
  到期题优先，不够再用未掌握题补，补不满就按实际数量
- **关于 → AI 题库转换提示词** —— 见本文第五节

> ⚠️ **手动加题只写内存，刷新即丢**——这一条现在也明明白白写在那个分组里。要长期保留请导出备份，
> 或者把题写回你的题库 JSON。
>
> ⚠️ 远程链接导入依赖目标服务器允许跨域（CORS）。如果对方不允许，改用「粘贴 JSON」或「选择文件」。

## 三、四个入口与六种练习模式

2.x 有 8 个入口，两两相似，很难判断该用哪个。3.0 收敛为 4 个一级导航，原来的六个刷题入口变成
**练习页顶部的一个分段控件**——差异只是判分方式和是否写长期进度，属配置而非入口。
完整对照表见 [README · 四个入口](../README.md#四个入口)。

| 2.x 入口 | 3.0 位置 |
|---|---|
| 首页 | 今日 |
| 学习 | 练习 › 背诵（模式 key `recite`，内部 session mode 仍是 `study`）|
| 练习 | 练习 › 答题（`answer` / 内部 `exercise`）|
| 分类考试 | 练习 › 按题型自测（`bytype` / 内部 `category`）|
| 模拟考试 | 练习 › 模拟考试（`mock` / 内部 `exam`）|
| 摸底速览 | 练习 › 浏览速览（`browse` / 内部 `preview`）|
| 记忆闯关 | 练习 › 闯关队列（`queue` / 内部 `practice`）|
| 数据管理浮层 | 题库页 |

练习页会**记住你上次用的模式**，六个模式各自的口径写在分段控件下方那一行里，不用猜。

### 今日 —— 今天该学什么

一屏只回答一个问题：今天要做什么。今日任务卡给出待学数、到期数、进度与预计用时，
旁边是可点改的**每日目标**芯片；往下是恢复提示卡（有未完成的会话时才有）、近 7 天学习量（学过之后才有）、
**记忆四档**（新题 / 学习中 / 需复习 / 已掌握）、**错题四档**（新错 / 巩固中 / 模糊 / 已攻克）。
有错题时，这一页就直接给「攻薄弱项」按钮，不必先去错题本。每张卡都带一行口径说明——数字要能解释来源。

### 背诵（原「学习」）—— 跨会话背题

设置：学习范围（今日复习 / 未掌握题目 / 全部题目 / 错题本 / 自定义范围，可指定起止与题型）、
队列生成（到期优先 / 顺序学习 / 随机洗牌）、每次数量（10 / 20 / 30 / 50 / 全部 / 自定义），
然后点 **开始背诵**。

一题一卡：先看题干 → **想好了，看答案** → 自评 **记住了** / **还不会**，也可以左右滑动（右滑记住、左滑还不会）。

- 记住了：跨会话进度前进，按连续答对次数排下次复习间隔（1 / 3 / 7 / 14 / 30 天），连对 5 次算「已掌握」
- 还不会：该题**实时**进错题本（来源标签仍显示 2.x 的「学习」）
- 中途按「暂停」会存恢复点；回到今日页能看到「继续上次的背诵 · 6 天前 · 第 3/4 题」这样的提示卡

### 答题（原「练习」）—— 自己作答、系统判分

设置练习范围（全部题目 / 未掌握 / 错题本 / 自定义）、出题方式（随机洗牌 / 顺序出题）与数量，点 **开始答题**。

- 客观题系统判分：判断题是**两个大按钮**，单选是**圆形单选点**，多选是**方形勾选框**且
  漏选/多选/错选都算整题错（界面里明写着「无部分给分」）。形状即语义，不是随便画的
- 填空题是**逐空输入**：一个空一个输入框、序号显式。题库里的 `"鸦片|1840"` 只在导入时拆成逐空答案，
  界面上不会再出现分隔符，也不用你手写竖线（2.x 那个「插入分隔符」按钮已经删掉了）
- 问答题是多行文本域（右下角实时显示字数）；主观题判分靠你自评 **算我答对** / **还是答错**——
  参考答案与自评按钮同屏出现，自评在答案下方，就是为了你先看见答案再判定
- 客观题答对后约 0.6 秒自动前进（这是节奏控制，`prefers-reduced-motion` 下也保留）；答错**停在本题**，
  下方立即给出标准答案与解析（带选项的题，选项文本和答案同屏可见）
- 底部只有一个主按钮：未提交时是 **提交答案**，提交后变成 **下一题** / **查看结果**；
  主观题自评完要点这一步。这一档没有「上一题」按钮，回看靠题干上方那行提示与宽屏的历史卡
- 题干上方有一行「之前：学过 N 次 · 上次答错 / 已掌握」的提示；768px 以上题面栏下面还有一张
  **「这道题的历史」**卡片（学过几次、上次结果、当前连对、有没有在错题本里）——移动端放不下，
  所以窄屏只有单栏、也没有这张卡
- 顶部有 **暂停**，进度自动保存；之后从今日页的恢复提示卡接着走

### 按题型自测（原「分类考试」）—— 挑题型实时判分

选择题型（可多选，或点「全选」），点 **开始自测**。答对短暂停留（约 0.6 秒）后自动下一题，
答错停在本题并展示答案与解析，同时**实时**进错题本。**上一题**可回看已答的题，作答状态完整恢复
（靠答题快照）。可随时点「退出」中断，已答错的题不会因中途退出而丢。主观题同样是揭示答案后自评。
这一模式的出题范围是「题型 + 随机」，与「答题」的「范围 + 数量」不同。

### 模拟考试（`mock`）—— 计时交卷，一次性判分

**过程中不反馈对错**：答题卡可以看、可以回看改答，但不告诉你对错。点 **交卷** 时走应用内确认对话框，
写明已答 / 未答数量。交卷后成绩页给出总题数、答对、答错、正确率、用时与错题列表，并明确：

> 正确率分母 = 已判分题数；待自评题不计分、未作答题不计分、不写进度、**不进错题本**。

主观题在成绩页逐题评定（待你评定区，**算我答对** / **还是答错**），评定完才计入。有恢复点，中断不丢。

### 浏览速览（原「摸底速览」）—— 只读，不判分

按顺序铺开全部题目，逐题 **查看答案 / 隐藏答案**，以及 **记入错题本**（来源标签仍是「摸底速览」）。
这一档刻意降级为浏览：**不判分、不写长期进度、没有恢复点**。要练请切「背诵」或「答题」。
适合考前 10 分钟扫一遍，或刚导入新题库时先看看有什么。

### 闯关队列（原「记忆闯关」）—— 会话内主刷

看题干 → **想好了，看答案** → 自评 记住了 / 没记住（这两个按钮的文案可以被题库 JSON 的
`features.practice.config.passLabel` / `failLabel` 覆盖）。没记住的卡片会被埋到 **5~7 张**之后，
保证中间至少隔四五道别的题才可能再刷到，同时实时进错题本（来源标签仍是「记忆闯关」）。
顶部显示剩余卡片数与已掌握数，队列清空后是「本轮队列清空」页，可 **再刷一遍**。

⚠️ 用词要注意：这里的「一次即掌握」在界面上叫**本轮攻克**，只影响本轮队列的顺序，
**不等于**跨会话的「已掌握」，两个数不可相加。若题库 JSON 写了 `features.practice.enabled: false`，
这个模式整块隐藏（旧开关键名不改不删，只是含义挪到了模式上）。

### 错题本 —— 集中攻克薄弱环节

错题本**全局去重**：同一道题无论在哪出错，只保留一条记录（来源更新为最新一次出错的场景）。

来源 Tab 的标签沿用 2.x 的数据值，所以你会看到旧名字——它们是数据，不是入口：

| 来源标签 | 由哪个模式产生 |
|---|---|
| 学习 | 背诵（点「还不会」或左滑，实时收录）|
| 练习 | 答题（客观题判错、主观题自评「还是答错」，实时收录）|
| 记忆闯关 | 闯关队列（点「没记住」，实时收录）|
| 摸底速览 | 浏览速览（点「记入错题本」）|
| 考试 | 模拟考试交卷判错 / 主观题自评为错、按题型自测答错，**实时**收录（中途退出不丢）|

Tab 只显示真实有题的来源（外加「全部」），默认停在「全部」，新加的错题不会因为分类是空的而看不见。

顶部四档：**新错 / 巩固中 / 模糊 / 已攻克**。前三档是**当前还在本子里**的题；「已攻克」是**历史累计**
（数据层新增移出留痕），它不计进错题总数——这条口径就写在卡片下面的说明条里。

**离开错题本只有一条规则**：

> 任何入口答对都计入连对，**累计连对 3 次自动移出**；中途答错一次，连对计数归零、状态退回。
> 移出时一定写明原因：**连对 3 次自动移出 / 手动删除 / 手动标记已攻克**。

2.x 那三条并行规则（重练连对 3 次移出、重考答对 1 次即移出、其它入口答对不计次）已经收敛成这一条。
行为上的变化是：**在背诵、答题、自测、考试、闯关里答对一道错题，现在都会推进它的出本进度**（以前不会）。
「错题重考答对一次就出本」的捷径没有了。

页内的操作：

- **攻薄弱项** —— 逐题自评（记住了 / 没记住），走上面那条唯一规则
- **错题重考** —— 组卷重考，交卷判分后同样只计连对，不再短路移出
- 每条错题：状态芯片、出错次数、连对计数；题干默认 2 行截断，点 **展开全文** 看完整；
  参考答案与解析同屏；**标记为已攻克** 与 **手动删除**（后者走应用内对话框确认）
- **清空错题本** —— 应用内对话框确认

> 命名不要混：记忆侧四档是 **新题 / 学习中 / 需复习 / 已掌握**，错题本侧四档是
> **新错 / 巩固中 / 模糊 / 已攻克**。它们在数据层有过同名的时候（都叫 `weak`），3.0 在界面上彻底
> 拆成两套词——**这是两个不同的数，不可相加**。

**未作答的题不会进错题本**：模拟考试里空着的题只在成绩页的「未作答」区列出，不计分也不收录。

错题总数在宽屏的侧栏导航项上以数字角标显示；移动端不带角标，320–359px 下从「更多」进错题本。

## 四、从 2.x 升级

**不需要做任何数据操作。** 不用导出再导入、不用清缓存、不用改题库 JSON：
`viewVersion` 保持 1.0.0，内部状态机、localStorage 键、恢复点的 `mode` 值、错题本的 `source` 值
全都沿用 2.x 原名，只有入口换了名字。已有的进度、错题本、恢复点、备份文件打开就接着用。
旧书签也全部有落点（新地址是 `#/today`、`#/practice/<mode>`、`#/wrongbook`、`#/bank`）。

你会注意到这些不同：

- 只有四个入口，六个模式收进练习页的一个分段控件里
- 数据管理不再是右上角浮层，而是「题库」这一页
- 主色从 iOS 蓝换成暖纸墨色，琥珀只作强调；主操作按钮是墨色；深色是暖黑
- 填空题改成逐空输入，界面上再也见不到 `|`
- 错题出本只剩一条规则，而且移出时一定告诉你原因
- 每日目标看得见也改得了；错题条目多了「标记为已攻克」和「展开全文」；
  恢复提示卡会写「什么时候留下的 · 第几题」
- 裸的 `#/practice` 仍按**旧地址**打开闯关队列（因为 2.x 里它就是记忆闯关的入口），
  而 3.0 自己生成的练习页链接一定带模式段

仍然存在的限制（诚实声明，与设计文档一致）：

- 色觉障碍模拟与屏幕阅读器实测**没有做**；状态区分靠「形状 + 文字」双线索，颜色只是冗余线索
- 折叠屏折痕按 24px 设计值留安全边，**未在真机测量**实际折痕宽度
- 七档断点是在真实 Chromium 上做的几何断言加逐档截图，不等于 iOS / Android 原生浏览器实测
- 「手动加题」仍只写内存、刷新即丢，界面上已写明这一条

## 五、用 AI 生成题库

点顶栏的 **AI 提示词**（星芒图标，弹窗展示；「题库 › 关于」里也有同一个入口），点「复制提示词」后
配合题目截图或文本丢给任意大模型，它会按规范输出可直接导入的 JSON。

典型流程：

1. 拍下练习册 / 试卷的照片
2. 复制本项目的提示词 + 贴图片，发给 AI
3. 拿到 JSON 后在「题库 › 导入 → 或粘贴 JSON 文本录入」里粘贴，点「应用粘贴的 JSON」
4. 顺手点「JSON 规则」下载规范，一并给 AI 效果更稳

## 六、数据存在哪

全部存在**浏览器 localStorage**，不上传任何服务器。
3.0 **没有改动任何 2.x 已有的键名和数据结构**，所以旧数据直接接着读；
新增的只有一个 `memo:practiceMode`（记录练习页上次用的模式，删掉也不影响数据，
只是回到默认的「背诵」）。停掉的是 `memo:showDataPanel`（2.x 那个数据管理浮层的开关，
浮层并进了题库页，它也就不再读写；老用户机器上残留的这个键可以不管）。

| Key | 内容 |
|---|---|
| `examBankCache:v2` | 题库缓存 |
| `examWrongbook:v1` | 错题本，**运行时唯一真相源**（3.0 在同一个对象里多了移出留痕 `history`，老数据按空数组读）|
| `examWrongbook:v2` | 迁移快照，只由一次性迁移写入、供导出使用；界面统计不读它 |
| `examProgress:v1` | 跨会话学习进度（新题 / 学习中 / 需复习 / 已掌握）|
| `examSession:v1` | 会话恢复点（背诵 / 答题 / 模拟考试三个模式有）|
| `examSettings:v1` | 设置，含**每日目标**（默认 20 题）|
| `examLeitnerQueue:v1` | 闯关队列 |
| `memo:theme` | 主题（auto / light / dark）|
| `memo:practiceMode` | 练习页上次用的模式（3.0 新增）|

因此：

- **换浏览器 / 换设备不同步** —— 用「题库 › 导出与备份」的导出备份，另一台导入备份
- **无痕模式关闭即丢** —— 别在无痕窗口里刷重要题库
- **清缓存会丢** —— 定期导出备份

## 七、常见问题

**Q：双击打开后是空白页？**
A：检查 `vendor/` 和 `js/` 目录是否和 `index.html` 在一起。它们必须保持相对路径结构。另外请勿用 IE —— 需要支持 ES2015+ 的现代浏览器（Chrome / Edge / Safari / Firefox 近几年的版本都行）。

**Q：我放了 `data.json` 为什么没加载？**
A：`file://` 协议下浏览器禁止 `fetch` 本地文件，属安全限制。用本地服务器打开即可（见 [部署指南](./DEPLOYMENT.md)），或直接拖拽文件导入。

**Q：导入后提示格式错误？**
A：确认 JSON 顶层有 `view: "exam-bank"` 和 `papers` 数组。不确定就点「JSON 规则」对照，或参考 `history-example.json`。

**Q：题目里的选项没显示？**
A：单选/多选题需要 `options` 字段（`{ "A": "选项内容", ... }`），App 会自动拼到题干下方。

**Q：出现一个我不认识的题型，会不会崩？**
A：不会。没注册的 `type` 走只读兜底：显示题干与 `answer` 原始字段，不提供作答、不写进度，
题型标签直接显示原始 `type` 字符串，方便你反馈给题库作者补字段。

**Q：2.x 的「数据管理」按钮找不到了？**
A：它升成了「题库」这个一级页（导入 / 手动加题 / 导出与备份 / 外观都在里面），不再是从右上角滑出来的浮层。

**Q：手动添加的题目刷新就没了？**
A：是的，这是已知限制，那个分组里也明明白白写着。要长期保留请导出备份，或把题写回题库 JSON。

**Q：我在背诵里答对了一道错题，为什么它还在错题本？**
A：因为现在只有**累计连对 3 次**才自动移出，而且任何入口的答对都算数。条目上的连对计数会告诉你走了几步。

**Q：键盘能用吗？**
A：能。空格看答案、Enter 提交 / 下一题、← 上一题、1–9 选择选项。键位徽标与侧栏的快捷键面板只在宽屏（1024px 以上）出现。

**Q：能多人共用一份题库吗？**
A：把 JSON 文件放静态服务器或对象存储上，用「远程导入」即可（记得开 CORS）。进度与错题本来就是个机的。
